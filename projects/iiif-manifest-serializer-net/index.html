IIIF.Manifest.Serializer.Net: IIIF Presentation API for .NET

A .NET library for building, reading, validating, converting and serializing IIIF Presentation API resources. It reads and writes versions 2.0, 2.1 and 3.0.

The problem

Presentation API 3.0 changed the shape of manifests, while plenty of 2.x JSON still exists. An application that handles both should not need two object models.

Design

  • Most resources use one model shaped like 3.0. Legacy 2.x properties are computed views over it.
  • IiifSerializer is the entry point. It detects the input version and writes 3.0 by default, or 2.x on request.
  • System.Text.Json converters produce the same IIIF JSON, including ASP.NET Core's default serialization.
  • The library tracks changes across the object graph and can produce changed-only manifest deltas.
  • Separate packages add navPlace, Georeference and Text Granularity support.

Install

dotnet add package IIIF.Manifest.Serializer.Net
var json = IiifSerializer.Serialize(manifest);
var parsed = IiifSerializer.DeserializeManifest(json);

Testing

The repository reports 557 unit tests, 8 architecture tests and about 82% line coverage for the core and extension packages. A cookbook project rebuilds 71 IIIF Cookbook recipes in C#.
